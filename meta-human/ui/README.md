# MetaHuman UI

This is the standalone React/Vite project archive. It runs without Python, camera or microphone access, model files, or API keys.

From the project root, double-click `run-ui.command`. Or run `npm ci` and `npm run dev` here, then open `http://127.0.0.1:5173`.

The homepage contains three development recordings. Feature Files documents the original voice conversation as twelve workflow stages plus two future concepts. Project Matrix presents potential deployment roles; it does not claim those integrations were built.

Checks:

~~~
npm run lint
npm run build
~~~

See the project-root `README.md` for the folder map and publishing cautions.
